# Дебиторка

Локальное web-приложение для учета начислений, оплат, остатков и штрафов по периодам.

Приложение подходит для `GitHub Pages`: данные хранятся локально в браузере пользователя через `localStorage`.

## Запуск

1. Установить зависимости:

```bash
npm install
```

2. Запустить приложение:

```bash
npm run dev
```

3. Открыть в браузере:

```text
http://localhost:8000
```

## Как передавать данные

- Экспортируйте базу через `Панель работы -> Импорт и экспорт JSON`
- Передайте полученный `.json` файл другому пользователю
- На другой копии приложения он сможет загрузить его через импорт
- После импорта данные сохранятся в его браузере локально

## Что умеет приложение

- хранить периоды и дедлайны
- добавлять компании, города, улицы и пригороды
- вести начисления и оплаты
- считать просрочку и штраф
- фильтровать и сортировать записи
- экспортировать и импортировать полное состояние базы в JSON

## Правило штрафа

- по умолчанию ставка штрафа: `0.01%` в день
- формула: `сумма платежа * 0.0001 * дни_просрочки`
- для непогашенного остатка штраф считается на дату расчета
